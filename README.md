# Abel

Suivi du bébé dans le navigateur (téléphone ou ordinateur).

```bash
npm install
npm run dev
```

Puis ouvrir [http://localhost:5173/abel/](http://localhost:5173/abel/).

En ligne : [https://mimom.be/](https://mimom.be/) — miroir [GitHub Pages](https://vincentchauvaux.github.io/abel/).

PWA installable depuis le navigateur. Pour une fiche **Google Play** (enveloppe TWA, pas l’App Store) : [`store/android/README.md`](store/android/README.md).
