Supprimer votre compte Mimom

Éditeur : Vincent Chauvaux — application Mimom (mimom.be)

Cette page décrit comment demander la suppression du compte Mimom et des données associées. La procédure se fait dans l’application, page Profil, une fois connecté avec Google.

1. Supprimer le compte et les données serveur

  1. Ouvrez Mimom (site ou application Android).
  2. Allez sur l’onglet Profil.
  3. Connectez-vous avec le compte Google lié, si ce n’est pas déjà fait.
  4. Dans la section données / RGPD, choisissez la suppression du compte (libellé du type Supprimer le bébé sur le VPS pour le propriétaire, ou quitter le partage pour un co-parent ou un gardien).
  • Propriétaire : le bébé et les données de suivi sont supprimés sur le serveur pour tout le monde ; l’album photos chiffré est effacé.
  • Co-parent ou gardien : vous quittez le partage. Les données du propriétaire ne sont pas effacées.

2. Effacer seulement cet appareil (sans supprimer le compte)

Sur Profil : Effacer les données sur cet appareil. Le cache local (IndexedDB) est vidé. Les données restent sur le VPS si un compte Google est encore lié.

3. Supprimer une partie des données (sans supprimer le compte)

Oui : dans le journal, chaque entrée peut être modifiée ou supprimée. Dans l’album, chaque photo peut être retirée.

Données supprimées ou conservées

  • Suivi (tétées, couches, sommeil, etc.) sur le VPS : supprimé si le propriétaire supprime le compte.
  • Album : fichiers chiffrés effacés si le propriétaire supprime le compte ; sinon photo par photo.
  • Session Mimom : jusqu’à 90 jours d’inactivité, ou tout de suite à la déconnexion / suppression.
  • Compte Google : Mimom ne supprime pas votre compte Google, seulement le lien avec Mimom.
  • Sauvegardes serveur : éventuellement quelques jours le temps des copies de sécurité OVH, puis purge.

Export préalable : Profil → Exporter mes données (JSON). Contact : GitHub Abel — Issues.
